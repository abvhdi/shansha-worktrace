# 珊莎工作留痕

一个本地优先的工作资料库，也是传统桌面应用与受控型 Agent 的结合：把散落的工作文件、任务和项目关系保存在自己的电脑上，需要时再搜索、关联或交给资料助手读取。

## 直接下载

普通用户不需要安装开发工具，请前往 [Releases 下载页](https://github.com/abvhdi/shansha-worktrace/releases/latest)，下载最新的 `Shansha-Worktrace-Mac-*.zip`。

当前公开安装包支持 Apple 芯片 Mac（M1、M2、M3、M4 及后续机型）。解压后，把“珊莎工作留痕”拖进“应用程序”即可。

由于当前版本尚未购买 Apple Developer 签名，第一次启动请：

1. 在“应用程序”中找到“珊莎工作留痕”。
2. 按住 Control 键点按应用，选择“打开”。
3. 在系统提示中再次选择“打开”。

如果 macOS 仍然阻止启动，可前往“系统设置 → 隐私与安全性”，在页面底部允许打开。

> 软件不会附带公共 AI Key。需要 AI 功能时，请在设置中填写自己的接口信息；不配置 AI 也可以使用本地资料、任务、项目和搜索功能。

## 它能做什么

1. 用户选择自己一直在使用的工作文件夹，软件自动识别第一层文件夹和已有文件。
2. 拖入 PDF、Word、图片、截图或文字文件。
3. 应用在本机读取文档正文或识别图片文字。
4. 如用户主动配置 AI 接口，则只发送脱敏后的文字进行分类。
5. 原文件从导入位置移入本地资料库，不额外产生重复副本。

## 当前支持

- PNG、JPG、WebP、BMP、TIFF 图片
- PDF、DOCX 和旧版 DOC 文档
- TXT、Markdown、CSV、JSON 文字文件
- macOS 系统内置的中文与英文 OCR（图片不会上传）
- Windows 内置离线中文 OCR 组件（图片不会上传）
- 本地基础分类
- DeepSeek、通义千问、OpenAI、Ollama 和 OpenAI 兼容自定义接口
- 本地全文搜索（文件名、正文、OCR、标签和任务），显示命中片段和关键词高亮
- 监听 Word、Excel、PPT 等原文件的修改并自动更新搜索索引；也可在记录中手工“重新读取”
- 风险提示、在文件夹中定位原件
- 默认使用“移动并归档”，原位置不保留重复副本
- 第一层文件夹与标签一一对应；新增、改名、删除标签时同步处理本地文件夹
- 修改文件标签时移动真实文件；项目只管理进度，不再决定文件位置
- 遇到同名文件会自动加编号，不会覆盖已有文件
- 全部记录、项目记录和任务列表，并按事情实际发生日期分组
- 独立任务收件箱：任务可以不属于项目，也可以之后再关联项目
- 任务可关联多份文件；从文件中识别出的任务会自动关联来源文件，也可手工增删关联
- 项目建议、人工确认、项目别名和负责人设置
- 独立项目管理入口，可新增、修改和删除项目
- 项目可按月份或自定义名称分组；分组只影响显示，不移动文件
- 可新增、改名、删除或整体关闭显示的文件夹标签；“其他”标签固定保留
- 每条记录可人工调整项目、分类和发生日期
- AI 可提取责任人、参与人、待办、决定和项目建议
- 项目概览页可由 AI 总结当前阶段、已完成事项、下一步和风险
- 项目进度按任务完成比例自动计算
- 项目待办可勾选完成、直接编辑、删除或人工补充负责人和截止日期
- AI 可从明确日期中提取任务截止时间，并在验证接口后开放文字输入
- 帮助与联系页面可跳转到 shansha.xyz
- 删除记录时可将对应原文件移到系统废纸篓
- 受控型资料助手：可搜索资料，读取 Word、Excel、PPT 等文件，查看项目进度，并显示来源记录
- 打开资料助手后可多选项目和文件作为本次对话上下文；所选文件会在提问时读取当前内容
- 资料助手可在用户预览并确认后生成 Word、Excel、PPT；写入资料库并关联任务或项目
- 修改已有 Office 文件时创建新副本，不直接覆盖原件
- 项目、文件和任务采用可搜索选择面板，支持多选、最近/已选内容置顶和键盘浏览
- 可导出和恢复项目、任务、标签、记录及关联关系；备份不包含 API Key 和原文件

## 隐私边界

- 文件索引、任务、项目和关联关系默认保存在用户自己的电脑上。
- 用户填写的 AI Key 不会被提交到本仓库或内置在安装包中。
- 默认先在本地 OCR；开启“混合识别模式”后，图片会发送给用户选择的视觉模型
- 软件检测到保密、密码等风险时显示提醒，但不自动禁止上传

- 手机号、身份证号和邮箱会在发送文字前遮挡。
- API 密钥使用操作系统的安全存储能力加密保存。

敏感信息检测只是一层辅助提醒，不能保证发现全部公司秘密或个人信息。

## 从源码运行

安装依赖后运行：

```bash
npm start
```

请从 Electron 应用或项目中的启动脚本打开工作台，不要直接双击 `src/renderer/index.html`；直接打开 HTML 不会加载桌面端的本地文件和资料库能力。

OCR 使用 macOS 自带的文字识别能力，不需要额外下载识别模型。

Windows 测试运行请阅读项目根目录的 `WINDOWS-README.txt`。Windows 第一次准备会安装该系统对应的 Electron 运行组件，之后可通过 `windows/02-open-worktrace.bat` 打开。
