珊莎工作留痕 Windows 测试版操作说明
================================

这是一份开发测试版本，不是正式安装包。

一、先安装 Node.js

1. 打开 https://nodejs.org/zh-cn/download
2. 下载并安装 LTS 版本。
3. 安装过程中保持默认选项即可。

二、第一次打开

1. 解压整个压缩包，不要只打开压缩包里的文件。
2. 进入 windows 文件夹。
3. 双击“01-first-run.bat”。
4. 等待运行组件准备完成，工作台会自动打开。

三、以后打开

双击 windows 文件夹中的“02-open-worktrace.bat”。

当前版本已经包含

1. 首页文件、图片和文字记录。
2. 选择原有工作文件夹后，自动识别已有文件和第一层文件夹。
3. 文件夹与标签双向同步；修改标签时同步移动真实文件。
4. 项目管理、全部记录、按项目分组的记录视图和任务列表。
5. 文件和任务全文搜索，并显示命中的内容片段。
6. 可搜索的项目、文件和任务选择面板；项目支持月份或自定义分组。
7. 自动发现 Word、Excel、PPT 等文件的修改并重新读取内容。
8. 可导出和恢复项目、任务、标签、记录及关联关系，备份不包含 API Key 和原文件。
9. AI 接口保存时自动验证，不需要再单独点击测试连接。
10. 混合识别模式：本地 OCR 后，可将图片和文字一起交给支持看图的模型。
11. 帮助与联系页面。
12. 删除记录时将原文件移到系统废纸篓。

四、重要说明

1. 不要把 node_modules 从 Mac 复制到 Windows。首次运行脚本会自动安装 Windows 版本。
2. 图片 OCR 默认在 Windows 本机运行；只有主动开启“混合识别模式”时，图片才会发送给用户选择的 AI 服务商。
3. PDF、Word、图片和文字文件都可以直接拖入；能读取的正文会用于自动整理。
4. 开启混合识别时，软件会明确提醒图片将上传；检测到风险时提醒，但不自动拦截。
5. 选择现有工作文件夹后，旧文件只建立索引，不会重新移动。
6. 拖入的新文件会从原位置移入对应的标签文件夹，不会再复制一份。
7. 第一层文件夹就是标签；项目只管理进度，不再决定文件位置。
8. “其他”是固定标签；删除普通标签时，里面的资料会安全移入“其他”。
9. 这是源码运行方式；测试稳定后再生成可直接安装的珊莎工作留痕.exe。

五、遇到问题

如果黑色窗口显示错误，请完整截图，不要只截最后一行。
