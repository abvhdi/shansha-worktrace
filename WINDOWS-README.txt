珊莎工作留痕 Windows 测试版操作说明
================================

这是一份开发测试版本，不是正式安装包。

一、先安装 Node.js

1. 打开 https://nodejs.org/zh-cn/download
2. 下载并安装 LTS 版本。
3. 安装过程中保持默认选项即可。

二、第一次打开

1. 解压整个压缩包，不要只打开压缩包里的文件。
2. 进入 windows 文件夹。
3. 双击“01-first-run.bat”。
4. 等待运行组件准备完成，工作台会自动打开。

三、以后打开

双击 windows 文件夹中的“02-open-worktrace.bat”。

当前版本已经包含

1. 首页文件、图片和文字记录。
2. 项目管理、全部记录、项目记录和任务列表。
3. 项目进度、任务负责人和截止日期。
4. AI 接口连接验证、文字补充和项目概览。
5. 帮助与联系页面。
6. 删除记录时将原文件移到系统废纸篓。

四、重要说明

1. 不要把 node_modules 从 Mac 复制到 Windows。首次运行脚本会自动安装 Windows 版本。
2. 图片 OCR 在 Windows 本机运行，图片不会为了识别文字而上传。
3. PDF、Word、图片和文字文件都可以直接拖入；能读取的正文会用于自动整理。
4. 如果用户主动配置云端 AI，只有经过脱敏的识别文字会发送给所选服务商。
5. 原始资料保存在用户自己选择的资料库中。
6. 这是源码运行方式；测试稳定后再生成可直接安装的珊莎工作留痕.exe。

五、遇到问题

如果黑色窗口显示错误，请完整截图，不要只截最后一行。
