珊莎工作留痕 · 新版 Mac 源码

打开方法：

1. 首次使用，双击 mac/01-first-run.command。
2. 以后使用，双击“打开珊莎工作留痕.command”或 mac/02-open-worktrace.command。
3. 第一次启动会安装适用于当前 Mac 的 Electron 与原生依赖，需要联网。

说明：

- 这是从新版 Windows 源码转换得到的独立 Mac 源码，不会覆盖旧版本。
- 文件、项目、任务与订单导出功能均保留。
- 新版可执行资料助手依赖额外的 agent-runtime。本源码暂未包含该运行环境；缺失时会自动使用原来的资料对话，不影响软件启动。
- 如需生成可分发的 Mac 压缩包，可在终端运行 npm run dist:mac。
- 当前生成的是未签名版本，其他 Mac 首次打开时可能需要在“系统设置 → 隐私与安全性”中允许。
